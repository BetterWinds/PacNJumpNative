Pac'N-Jump for Android

The 2011 game was pulled from the stores. This is a rebuilt version that runs on current Android phones. It ships with none of the original art or sound: you give it your own copy of the original Android APK, and this page builds an installable app from it.

Everything happens in your browser. Your APK is not uploaded anywhere.

Drop your original Pac'N-Jump APK here or tap to choose the file
    Download PacNJump.apk

    Installing it

    1. Needs a 64-bit Android phone running Android 7.0 or newer.
    2. Download the APK on the phone (or copy it over). Open it from your Files app or the browser's download list.
    3. Android will ask you to allow installs from that app (Files, Chrome, whichever opened it). Turn that on for it once.
    4. If Play Protect warns about an app it hasn't seen, tap More details, then Install anyway.
    Notes

    The app is signed with a key this page creates and keeps in your browser. Building again in the same browser gives an APK that updates the installed one. A different browser makes a different key, so uninstall the old copy first.
